# assets 文件夹（小满出行）

把视频和音乐放在**这个文件夹里**，文件名必须是：

- `intro.mp4` —— 介绍区的背景视频
- `bgm.mp3` —— 背景音乐

## 目录结构

```
E:\deepseek H工作区\
├── 小满出行.html     ← 主文件（也可以改名为 xiaoman.html，路径不受影响）
└── assets\
    ├── intro.mp4     ← 视频放进这里
    ├── bgm.mp3       ← 音乐放进这里
    └── 检查素材.html  ← 用来验证素材能否被播放
```

## 注意

1. **文件名要完全一致**：`intro.mp4` / `bgm.mp3`，注意不要变成 `intro.mp4.mp4` 或 `intro (1).mp4`。
2. **扩展名要真的对得上**：很多下载的视频是 `.webm`、`.m4a`、`.m4v`，音乐是 `.m4a`、`.wav`、`.flac`——这些名字不是 `.mp4`/`.mp3` 时，播放器会直接报错。用 `检查素材.html` 可以验证。
3. **扩展名不一样也能用**：只要告诉我真实扩展名，我可以改 `小满出行.html` 里 `<source>` 的 `type`，不用你去转码。
4. **找不到合适的素材时**：不用勉强，直接打开 `小满出行.html`，视频会自动降级成 CSS 渐变动画，音乐会自动降级成 Web Audio 生成的环境音，功能完全不受影响。
