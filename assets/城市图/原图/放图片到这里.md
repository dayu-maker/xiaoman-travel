# 把下载的照片放进这个文件夹

## 怎么做

1. 从免费图库下载城市照片（推荐 Pexels、Unsplash，免费可商用、不用登录）
2. 把图片文件复制到这个文件夹
3. **把每张图重命名为城市名**，扩展名保持原样

例如：

```
原图\
├── 大理.jpg      ← 大理的照片
├── 丽江.jpg      ← 丽江的照片
└── 三亚.png      ← 三亚的照片（png 也行）
```

## 文件名必须是这样（共 18 个）

北京　上海　杭州　苏州　成都　西双版纳　丽江　大理　三亚
厦门　青岛　昆明　贵阳　桂林　西安　珠海　大连　鼓浪屿

⚠️ 只能是**纯城市名**：`大理.jpg` 对，`大理古城.jpg`、`dali.jpg`、`大理 (1).jpg` 都不行。

## 然后

回到上一级目录，右键 `批量处理图片.ps1` →「使用 PowerShell 运行」。

脚本会把这些原图裁成卡片比例、压缩、并按城市名输出到 `assets\城市图\`，
再刷新 `小满出行.html` 就能在卡片上看到照片了。

**先只放一张试**（比如 `大理.jpg`），确认流程走通了，再把剩下的补齐。
