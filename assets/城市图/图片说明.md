# 城市卡片配图 · 使用说明

把城市的景色照片放进这个文件夹，**文件名必须是城市名**，卡片会自动使用它。
没有对应文件的卡片，会自动保持现在的「渐变底 + 图标」样式，不会报错、不会留空。

## 支持的格式（按优先级）

```
城市图\大理.jpg
城市图\大理.jpeg
城市图\大理.png
城市图\大理.webp
```

四种都行，程序会依次尝试。**文件名必须是纯城市名**，例如 `大理.jpg`，
不能是 `大理古城.jpg` 或 `dali.jpg`。

## 图片建议

- **尺寸**：横图，比例接近 3:2 或 16:9 最好（卡片图位实际显示约 340×134，会被裁切填满，所以主体尽量居中）
- **体积**：单张控制在 200KB 以内，18 张总共 3–4MB 比较合适；太大首屏会变慢
- **版权**：用可商用的免费图库，例如 Unsplash、Pexels、Pixabay；搜索城市名 + landmark 即可
- **光线**：偏明亮、低饱和的照片和现在的莫兰迪配色最搭

## 临时想快速验证

只放一张 `大理.jpg` 进去即可 —— 刷新页面后，应该只有大理这张卡片变成照片，
其余 17 张仍是渐变底。这样能立刻确认路径和命名是否正确。
